# Bez: русское интерактивное меню и диагностика приложений

## Цель

Сделать команду `bez` основным русскоязычным интерфейсом: пользователь выбирает
режим цифрой, видит объяснение local/global proxy, может проверить Cline и
получить готовую настройку для браузера/VS Code без запоминания флагов.

## Файлы и границы

- `src/macos-installer.ts` — shell-CLI, меню, режим `--global`, проверки Cline и
  подсказки для приложений.
- `tests/macos-installer.test.ts` — контракты сгенерированного CLI: русское меню,
  глобальный override, `check`, `cline` и отсутствие регрессии bundle offline/local.
- `docs/superpowers/plans/2026-07-24-bez-interactive-ru.md` — этот план и
  фиксированный scope.

## Порядок реализации

1. Добавить падающие тесты на новые пункты меню, `--global`, `bez check` и
   `bez cline`; запустить только `tests/macos-installer.test.ts` и убедиться,
   что падение связано с отсутствующей функциональностью.
2. Переписать `interactive_bez()` в циклическое русское меню с режимами:
   local smart, local all, global smart, global all, проверка, подсказка Cline,
   статус и выключение. Плохой ввод не должен завершать CLI.
3. Изменить разбор активации: bundle по умолчанию остаётся offline/local, но
   пункт global передаёт `--global` и явно включает системный proxy. Поддержать
   `--global` как технический alias без необходимости пользоваться им вручную.
4. Добавить `check_bez()` с проверкой `app.cline.bot`, `api.cline.bot`,
   `chatgpt.com` и `claude.ai` через локальный HTTP proxy. Результат должен
   различать HTTP-ответ, DNS/соединение и ошибку локального proxy.
5. Добавить `cline_bez()` с фактическими локальными портами, переменными
   `http_proxy`/`https_proxy` и настройкой VS Code `http.proxy`; команда не
   должна менять файлы или системные настройки.
6. Запустить focused tests, `npm run build`, полный `npm test`, затем проверить
   сгенерированный shell через `bash -n` и реальный `bez check` на Mac через
   `localhost:2222`.

## Критерии готовности

- `bez` показывает русское меню и не требует флагов.
- `bez all` в bundle остаётся local-only.
- Глобальный режим доступен пунктом меню и командой `bez all --global`.
- `bez check` показывает, что Cline доступен через proxy даже при проблемном
  прямом DNS.
- `bez cline` даёт точные параметры HTTP proxy для VS Code/браузера.
